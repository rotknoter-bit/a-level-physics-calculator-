A-Level Physics Equation Engine

A programmatic algebraic solver designed to dynamically manipulate variables, isolate unknown metrics, and evaluate multi-step systems of physics equations.

 Core Features
*Dynamic Variable Isolation:** Automatically rearranges complex algebraic formulas based on user-selected target outputs.
* **Equation Library:** Houses the complete catalog of AQA A-Level Physics equations (e.g., kinematics, waves, mechanics, and fields).
* **Automated Computation:** Evaluates inputs instantly, handling mathematical processing without requiring manual transformation steps.

Tech Stack
* **Language:** Python
* **Key Mechanics:** Algorithmic conditional logic and control structures for formula inversion.

Future Enhancements
* Implementing SI Unit conversion mapping to automatically handle prefixes (e.g., mm, kN, MHz).
* Adding a visual plotting module using Matplotlib to graph the output curves (e.g., constant acceleration graphs).
